# WordPress Hosting Investigation Checklist

## Server Health Checks

- [ ] Check uptime
- [ ] Check CPU load
- [ ] Check memory usage
- [ ] Check disk space
- [ ] Check swap usage

---

# Web Server Checks

- [ ] Verify Apache/LiteSpeed status
- [ ] Verify PHP processing
- [ ] Check active connections
- [ ] Check virtual host configuration

---

# Database Checks

- [ ] Verify MySQL/MariaDB service
- [ ] Confirm database connectivity
- [ ] Check database errors
- [ ] Review slow queries if necessary

---

# WordPress Checks

- [ ] Verify wp-config.php
- [ ] Check plugin conflicts
- [ ] Check Elementor compatibility
- [ ] Review theme compatibility
- [ ] Clear cache
- [ ] Verify file permissions

---

# Log Investigation

- [ ] Review Apache logs
- [ ] Review PHP logs
- [ ] Review WordPress debug logs

---

# Resolution Validation

- [ ] Confirm website accessibility
- [ ] Confirm Elementor functionality
- [ ] Confirm inner pages load correctly
- [ ] Confirm no major errors remain

---

# Important Note

Hosting-side validation should always be completed before escalating issues to application-level debugging.
