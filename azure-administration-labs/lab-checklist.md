# Azure Administration Lab Checklist

- [ ] Create Azure VM
- [ ] Assign VM size
- [ ] Configure authentication
- [ ] Assign public IP
- [ ] Validate VM connectivity

---

# Networking Tasks

- [ ] Create Network Security Group
- [ ] Configure inbound rules
- [ ] Configure outbound rules
- [ ] Validate SSH/RDP access
- [ ] Review subnet configuration

---

# Storage Tasks

- [ ] Create storage account
- [ ] Review blob storage
- [ ] Validate storage access
- [ ] Review access permissions

---

# Backup Tasks

- [ ] Review Recovery Services Vault
- [ ] Configure backup policy
- [ ] Enable VM backup
- [ ] Validate recovery points

---

# Monitoring Tasks

- [ ] Review VM metrics
- [ ] Check monitoring dashboards
- [ ] Review alerts
- [ ] Validate infrastructure health

---

# Security Tasks

- [ ] Review NSG rules
- [ ] Validate restricted ports
- [ ] Review identity/access configuration

---

# Important Note

Cloud administration requires continuous monitoring, backup validation, and security review.
