# Azure Administration Labs

## Overview

This repository documents hands-on Microsoft Azure administration activities involving virtual machines, networking, backup configuration, storage management, monitoring, and infrastructure validation.

The purpose of these labs was to strengthen practical cloud administration skills and understand Azure infrastructure management workflows.

---

# Environment

- Microsoft Azure
- Azure Virtual Machines
- Azure Storage Accounts
- Azure Networking
- Azure Backup
- Azure Monitoring
- Azure Data Lake
- Azure Portal

---

# Objectives

- Deploy and manage Azure virtual machines
- Configure Azure networking components
- Implement backup policies
- Configure monitoring
- Explore Azure storage services
- Practice cloud infrastructure administration

---

# Lab Activities

## 1. Virtual Machine Deployment

Activities included:

- VM creation
- VM sizing
- authentication configuration
- public IP assignment
- resource group management

---

## 2. Network Security Group (NSG) Configuration

Tasks included:

- creating NSGs
- allowing required ports
- reviewing inbound/outbound rules
- validating connectivity

Example services reviewed:

- SSH
- RDP
- HTTP
- HTTPS

---

## 3. Azure Backup Configuration

Activities included:

- backup vault review
- backup policy assignment
- VM backup configuration
- recovery point validation

---

## 4. Azure Storage Administration

Tasks included:

- storage account review
- blob storage exploration
- access configuration
- storage validation

---

## 5. Azure Monitoring

Monitoring activities included:

- VM health review
- metrics monitoring
- alert review
- infrastructure visibility checks

---

## 6. Azure Data Lake Exploration

Activities included:

- reviewing storage hierarchy
- understanding data organization
- validating access structure
- exploring cloud storage concepts
