# Post-Migration Checklist

## Website Verification

- [ ] Confirm websites load correctly
- [ ] Confirm homepage loads
- [ ] Confirm admin panels work
- [ ] Confirm database connectivity
- [ ] Confirm images/assets load properly

---

# DNS Verification

- [ ] Confirm DNS resolution
- [ ] Confirm correct IP assignment
- [ ] Confirm propagation status
- [ ] Remove local hosts file entries

---

# SSL Verification

- [ ] Check SSL certificates
- [ ] Confirm HTTPS redirects
- [ ] Verify no SSL warnings

---

# Email Verification

- [ ] Check incoming mail
- [ ] Check outgoing mail
- [ ] Confirm SMTP functionality
- [ ] Check SPF/DKIM records

---

# Server Verification

- [ ] Check server load
- [ ] Check Apache status
- [ ] Check MySQL status
- [ ] Check disk space
- [ ] Check backup configuration

---

# Backup Verification

- [ ] Verify backup destination
- [ ] Confirm automated backups enabled
- [ ] Test backup generation
- [ ] Verify restore capability

---

# Important Notes

Post-migration monitoring is critical during the first 24–48 hours after cutover.
